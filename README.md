# ABS投资跟进系统

## 项目简介

这是一个基于Streamlit构建的ABS（资产支持证券）投资数据分析和管理平台，提供多维度的投资分析、产品管理和流动性管理功能。

## 主要功能

### 1. 核心投资指标
- 展示关键投资统计数据
- 投资组合概览
- 收益分析

### 2. 产品分析
- 产品维度数据分析
- 持仓份额计算
- 产品表现对比

### 3. 资产分析
- 底层资产分析
- 资产质量评估
- 风险指标监控

### 4. 交易记录
- 交易历史查询
- 交易统计分析
- 交易趋势展示

### 5. 产品参数 ⭐ 新增
- 产品要素管理
- 申购赎回到账时间配置
- 产品渠道信息管理
- 快速查询工具

### 6. 流动性管理表 ⭐ 新增
- 产品现金流明细管理
- 母子基金联动操作
- 流动性仪表盘
- 余额趋势分析

## 技术栈

- **前端框架**: Streamlit
- **数据处理**: Pandas, NumPy
- **数据可视化**: Plotly
- **Excel处理**: OpenPyXL
- **统计计算**: SciPy

## 安装依赖

```bash
pip install -r requirements.txt
```

## 启动应用

### 方法1：使用启动脚本（推荐）
```bash
run_app.bat
```

### 方法2：命令行启动
```bash
streamlit run app.py
```

启动后在浏览器中访问: http://localhost:8501


## 使用说明

### 产品参数页面
1. 在侧边栏选择"产品参数"
2. 查看和编辑产品要素信息
3. 使用搜索功能快速查找产品
4. 配置申购赎回到账时间

### 流动性管理表页面
1. 在侧边栏选择"流动性管理表"
2. 上传或选择流动性管理Excel文件
3. 查看产品现金流明细
4. 执行母子基金申购/赎回操作
5. 监控流动性仪表盘

## 数据文件说明

- **产品要素表.xlsx**: 存储产品基本信息和申赎规则
- **基金流动性管理总表.xlsx**: 存储各产品的现金流数据
- **data.xlsx**: 主要投资数据
- **交易记录.xlsx**: 历史交易记录
- **项目库.xlsx**: 项目基础信息

## 注意事项

1. 首次使用前请确保所有依赖包已正确安装
2. 数据文件应放置在项目根目录下
3. 修改数据后记得保存
4. 建议定期备份重要数据文件

## 开发说明

### 添加新页面
1. 创建新的页面文件（如 `page_xxx.py`）
2. 实现 `render_xxx()` 函数
3. 在 `app.py` 中导入并注册新页面

### 代码规范
- 使用中文注释
- 遵循PEP8编码规范
- 函数命名清晰明了
- 保持代码模块化

## 常见问题

**Q: 如何修改菜单项？**
A: 在 `app.py` 的侧边栏配置部分修改 `options` 列表

**Q: 数据不显示怎么办？**
A: 检查数据文件路径是否正确，文件格式是否符合要求

**Q: 如何自定义样式？**
A: 在 `app.py` 的CSS样式部分进行修改
